# Get Started

## 🚀 Installation

### 1. **Download the latest release**

Go to the [Releases page](https://github.com/scifisatan/buzzlink/releases) and download the binary that matches your operating system and CPU architecture:

- **Linux**: `buzzlink-linux-amd64`, `buzzlink-linux-arm64`, etc.
- **macOS**: `buzzlink-darwin-amd64`, `buzzlink-darwin-arm64`, etc.
- **Windows**: `buzzlink-windows-amd64.exe`, etc.

### 2. **Install the binary**

After downloading, move the binary to a directory in your `PATH` (e.g., `/usr/local/bin` on Linux/macOS, or a folder in your `%PATH%` on Windows):

```bash
# On Linux/macOS
chmod +x <downloaded-binary>
sudo mv <downloaded-binary> /usr/local/bin/buzzlink
```

On Windows, rename the file to `buzzlink.exe` if desired and move it to a folder in your `%PATH%`.

> Make sure the install location is in your system's `PATH` so you can run `buzzlink` from anywhere.

---

## 🔄 Upgrade & Uninstall

### 🔼 Upgrade

To upgrade, simply download the latest release for your OS/arch and replace the existing binary as above.

### 🗑 Uninstall

To remove BuzzLink, simply delete the binary file you installed:

```bash
# On Linux/macOS
sudo rm /usr/local/bin/buzzlink
```

On Windows, delete the `buzzlink.exe` file from the folder where you placed it.

If you installed it elsewhere, remove it from that location.
